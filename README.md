# 盘灵互通核心组件
**注意：当前版本尚未支持 Geyser >=2.9.3**，即自定义映射 v2 实装版本

## 📖 简介

依「盘灵古域」系列内容适配互通的功能需求，扩展 Geyser 的功能




## ⚙️ 功能

- 实现药水根据颜色映射为自定义物品
  - 需要通过 Geyser 为物品定义自定义模型映射，其 Custom model data (CMD) 值为 MC 格式的药水颜色 (R*255*255 + G*255 + B) 的，并确保定义顺序为 CMD 值由小到大
  - 当物品实例带有药水颜色属性，系统会匹配此物品的 ID 下，CMD 与此颜色最接近的自定义物品映射 (欧式距离算法，含加权)
    - 比如游戏内有以下物品实例:
      - 药水1，颜色为 #f82423: `potion[potion_contents={custom_color:16262179}]`
      - 药水2，颜色为 #87A363: `potion[potion_contents={custom_color:8889187}]`
    - 定义以下自定义物品映射 (按 CMD 值由小到大排序):
      - 自定义1，CMD 值为 5149489 (#4e9331)
      - 自定义2，CMD 值为 16262179 (#f82423)
    - 效果
      - 药水1 -> 自定义2 (颜色 #f82423 完全匹配)
      - 药水2 -> 自定义1 (和 #87A363 最相似的颜色是 #4e9331，而非 #f82423)
  - 实现原理: 修改 Geyser 收发的网络数据包
- 药水堆叠 (需配合服务端物品组件/插件，以及自定义物品)
  - 已预留可扩展为更多基岩版自定义物品属性的设置的接口，补全 Geyser 有限的选项，充分利用客户端特性




## 💿 兼容性

- 基于 Bukkit 的服务端 (如Spigot、Paper)
- Velocity 代理 (WIP)
- Geyser 独立版 (作为 Geyser 扩展使用)

所有平台均使用统一的 Jar 包




## 🔨 构建

- 使用 Gradle 构建: 项目目录下使用 `./gradlew build`
- 成品 Jar: `build/libs/PCUB-Core.jar`
  - 适用于所有兼容的平台

有关 geyser 子项目 (包括在其它子项目内的): 其中的代码通常涉及到 Geyser 的底层，而 Geyser 在不同平台下所使用的部分依赖被 relocate 重定位，故这里也需要针对不同平台做不同处理。
